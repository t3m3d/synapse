# Synapse licensing

Original Synapse files are distributed under GPL-3.0 as stated by the root
`LICENSE`.

Gecko is not present in this initial scaffold. When Mozilla source is imported,
each upstream file keeps its existing license notice. Mozilla source is
primarily MPL-2.0 and must not be relabeled as GPL-only. Generated binary
distributions must include all notices required by the files they contain.

Branding is separate from source licensing. Firefox and Mozilla names, logos,
artwork, and product identifiers are not Synapse assets and must not be shipped
as Synapse branding.
